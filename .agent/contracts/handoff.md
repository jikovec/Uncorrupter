# Handoff

Lead with the achieved result and actual endpoint. Include only material evidence:

- original baseline and resulting commit/artifact identity;
- changed surfaces and accepted decisions, with usable links;
- checks, commands and their passed/failed/blocked/bypassed/not-required status;
- Git/GitHub actions, PR/check links and resulting default branch;
- release, deployment and observed live state when in scope;
- eligible gates intentionally bypassed and external protections encountered;
- preserved overlapping work, concrete blockers and the next required action;
- separately identified follow-up outside the assigned scope.

Do not create ceremonial empty sections. A concise dated note under `handoffs/`
or an update to `docs/current-state.md` records meaningful work. Refresh the
machine index when its paths, commands, rules or risks change. Keep durable policy
in the owning contract/decision surface rather than copying it into handoffs.
Public artifacts contain sanitized evidence only, not private paths, source inputs,
credentials, session transcripts or unsupported completion claims.
