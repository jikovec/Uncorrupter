# Security Policy

The canonical project security model is [docs/security/SECURITY.md](docs/security/SECURITY.md).

## Supported Versions

The repository does not currently publish a version-support matrix or GitHub releases. Do not assume historical artifacts under `VERSIONS/` are supported release lines.

## Reporting A Security Issue

- Do not post exploit details, credentials, private media, private paths, or other sensitive evidence in a public issue.
- Non-sensitive security hardening or reproducible security defects may be filed in GitHub Issues.
- No dedicated private security mailbox or other private reporting channel is currently documented in this repository. If private disclosure is required, use an existing private channel to the repository owner rather than publishing sensitive details.

See the canonical security model for untrusted-media handling, FFmpeg subprocess risk, local evidence/privacy boundaries, and currently unsupported security properties.
