# Support

This repository does not currently promise a support SLA or provide a dedicated user-support channel.

Use these routes:

- Read [README.md](README.md), [docs/INDEX.md](docs/INDEX.md), and [docs/api/CLI.md](docs/api/CLI.md) for setup and CLI behavior.
- Use GitHub Issues for reproducible bugs, narrowly scoped feature requests, and non-sensitive repository problems.
- Use [SECURITY.md](SECURITY.md) for security-reporting rules. Do not disclose sensitive vulnerability details publicly.

When opening an issue, include the command used, expected behavior, observed behavior, relevant error output, Python version, and whether FFmpeg/ffprobe were available. Remove private file paths, private media details, credentials, and other sensitive data first.
